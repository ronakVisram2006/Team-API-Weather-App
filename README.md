# Team Weather App

A React application built using **Vite**.  
This project demonstrates a fast development workflow, hot module replacement (HMR), and a clean component-based structure.

---

## 🚀 Requirements

Before running the project, make sure you have the following installed:

### 1. Node.js (LTS recommended)
Download from: https://nodejs.org

Check installation:
node -v npm -v


### 2. npm  
Comes bundled with Node.js.

---

## 📦 Installation

After downloading or unzipping the project:

1. Open a terminal in the project folder:

cd Team-Weather-App


2. Install all dependencies:
npm install


This will recreate the `node_modules` folder (removed for submission).

---

## ▶️ Running the Project (Development Mode)

Start the Vite development server:
npm run dev


You will see a local URL such as:
http://localhost:5173


Open it in your browser to view the app.

---

## 🏗️ Building for Production

To generate an optimized production build:

npm run build


This creates a `dist` folder containing the final output.

---

## 🔧 Preview Production Build (Optional)

To preview the built app locally:

npm run preview
